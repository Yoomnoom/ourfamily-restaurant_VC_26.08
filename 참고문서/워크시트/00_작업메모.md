# 작업 메모 — 0~8단계 워크시트 채우기 (자동 작성, 2026-08-17 밤)

> 자는 동안 0~8단계 워크시트를 전부 채워봤어. 이 파일은 "무엇을 실제로 확인/설명해줘야 하는지"만 모아둔 요약본이야 — 각 단계 파일 안에도 같은 표시(🔖 메모)로 남겨뒀지만, 한 번에 훑어볼 수 있게 여기 다시 모음.

## 꼭 필요한 것 (내가 대신 만들 수 없는 것)

1. **3단계 A. 실제 인터뷰 1건** — 진짜 사람을 인터뷰한 내용이 전혀 없어서 완전히 비워뒀어. 이건 내가 지어내면 안 되는 항목이라(워크시트의 핵심 취지 자체가 "AI 가상 페르소나만으로 끝내지 말라"는 거라서) 진짜로 가족 중 한 명(또는 비슷한 처지의 지인)을 붙잡고 5~6분 인터뷰한 내용을 채워줘야 완성돼.
2. **1단계 ③ 데이터랩 검증** — 네이버 데이터랩 실제 조회가 필요한 수치(검색 트렌드, 연령대별 관심도, 기기 비율)라 AI가 접근할 수 없어서 비워뒀어. 관련 키워드 후보는 적어뒀음("가족 식사", "저녁 뭐 먹지", "가족 일정 공유" 등).
3. **0단계 팀명·팀원** — "팀원"란에 이름은 "윰"(4단계 문서에서 확인) 하나만 확인되고 나머지(팀명, 다른 팀원 유무)는 몰라서 비워둠.
4. **1단계 ① AI 질문(발산) 7개 중 못 채운 5개** — 실제로 발산 단계에서 어떤 다른 아이디어 후보들이 있었는지 기록이 안 남아있어서, 확인되는 2개(우리집식당, 냉장고 파수꾼 — 후자는 FEATURE_CATALOG.md에 "세션 중 별도 앱에서 이식"이라고 적혀있어 추정)만 채우고 나머지는 비워둠.

## 확인/재검토가 필요한 것 (일단 채웠지만 검증 필요)

5. **3단계 ③ 경쟁사 벤치마킹** — 실제 스토어에서 직접 조사한 게 아니라 웹 검색으로 찾은 실제 서비스(TableMesh, Meal Train, Cozi)를 근거로 채웠어. 진짜 앱스토어 들어가서 리뷰·스크린샷 보고 다시 확인하면 더 정확해질 거야.
6. **1단계 ④ TAM/SAM/SOM 추정** — 실제 데이터 없이 일반적인 한국 가구 통계 지식으로 추정한 숫자라 "AI 추정치"라고 표시해뒀어. 참고용으로만 봐줘.
7. **2단계 5 Whys, HMW** — 실제 세션에서 나온 원본 대화가 없어서, 지금까지 쌓인 DECISIONS.md·PRD의 근거를 거꾸로 재구성한 거야. 순서상 앞뒤가 바뀌었을 수 있어(보통 5 Whys가 먼저고 그 결과로 기능이 나오는데, 지금은 이미 완성된 기능에서 왜 그랬을지 역산함) — 실제 그때 그렇게 생각했는지는 확인 필요.
