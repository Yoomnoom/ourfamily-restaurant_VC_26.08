# 우리집식당

> 묻지 않아도 아는 집 — 가족·룸메이트끼리 "오늘 뭐 먹어?"를 매번 안 물어봐도 되게 해주는 식사 계획 앱

정적 HTML(화면별 `code.html`) + [Supabase](https://supabase.com) 백엔드로 만든 PWA입니다. 별도 빌드 과정 없이 정적 파일을 그대로 서빙합니다.

## 실행 방법

- **로컬**: 저장소 루트에서 정적 서버를 띄우고 `index.html`로 접속
  ```
  npx serve
  # 또는
  python -m http.server 8080
  ```
- **배포**: GitHub Pages (`main` 브랜치 push 시 자동 반영)

## 화면 구성

화면마다 폴더 하나씩(`N-M. 화면이름/code.html`)으로 되어 있고, 서로 상대경로(`../`)로 연결돼 있습니다.

| 구분 | 화면 |
|---|---|
| 온보딩 | 1-1 회원가입 · 1-2 시작하기 · 1-3 가구프로필 · 1-4 가족구성원 |
| 로그인/계정 | 2-1 로그인 화면 · 2-2 로그인 · 2-3 비밀번호 재설정 |
| 식사 흐름 | 3-0 홈 · 3-1 내 식탁 · 3-2 식사 만들기 · 3-3 참여자 응답 · 3-4 확정 전 요약 · 3-5 오늘의 식탁 완성 · 3-8 참여자 링크 공유 · 3-9 무가입 응답 연결 |
| 달력 | 4-1 홈 달력뷰 |
| 가구·설정 | 5-1 가구 설정 · 5-2 식사 기록 · 5-3 설정 · 5-4 요일별 기본 응답 · 5-5 메뉴 대표 사진 |
| 오류·복구 | 6-1 오류·복구 상태 · 6-2 계정 복구 |
| 냉장고·추천 | 7-1 우리집 냉장고 · 7-3 메뉴 추천 |
| 부가 기능 | 8-1 밀키트 주문 · 8-2 식사 사진 기록 · 8-3 식비 예산 · 8-4 정산 |
| 개발용 | 0_개발도구 0. 확인용뷰어 — 화면 전체를 사이드바에서 미리보기하는 내부 도구 |

## 공용 코드

- `shared/supabase-client.js` — Supabase 클라이언트 초기화, 세션/가구원 조회, 전역 오프라인 배너
- `shared/api.js` — 화면들이 공유하는 도메인 함수 모음(인증, 가구, 식사, 알림 등)
- `sw.js` / `manifest.json` — PWA 설치·오프라인 지원
